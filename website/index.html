Yours, and private

Runs on your machine

Self-host with Docker. Your library is stored on your computer, and only reachable from it unless you choose to connect a remote tool.

Bring your own key

Note text is sent only to the AI provider you choose (OpenAI or Anthropic), under your own key, to index it and write answers. Want nothing to leave your machine? Use Ollama, with no key at all.

Open source

Apache 2.0 licensed. Read the code, change it, add your own connectors.

Get started

You need Docker, git and one OpenAI API key. Full checklist: Before you start.

  1. Download and add your key 
    git clone https://github.com/munkymind/munkymind.git
cd munkymind
cp .env.example .env      # then put your OPENAI_API_KEY in .env
  2. Add some notes and start it 
    mkdir -p notes && cp -r ~/path/to/your/notes/* notes/
docker compose up -d

    No notes handy? Set MM_NOTES_DIR=./examples/sample-notes in .env to try a small made-up library.

  3. Run the setup wizard (creates your user, ingests your notes, test-queries) 
    docker compose exec api munkymind setup

    Save the mm_sk_… key it prints. Then ask: docker compose exec api munkymind query --user yourname "What am I working on?"

  4. See your brains. Open http://localhost:8000/ui and paste your key to browse what it learned.
  5. Connect your AI tools. Claude Desktop works locally. For claude.ai or ChatGPT, give the MCP server a public HTTPS address (a free Cloudflare tunnel works) and add it as a custom connector. Step-by-step guide.

Once it's running

🧠 See your brains

A local viewer at localhost:8000/ui. Every topic is a brain: Body Brain, Business Brain, Big Picture Brain. Browse and search what each one knows, and see where it came from.

👀 Peek

Type a question and see exactly which few snippets your AI would be sent, and how small that is next to your whole library. No AI is called.

😋 Keep it fresh

Brains get hungry. Each one shows a mood, from 😋 fed to 😴 starving, so you know which notes are out of date before your AI relies on them.
