Your context, in every AI tool.

Your AI tools forget you every conversation. Munkymind is an open-source personal context library: point it at your notes, and Claude, ChatGPT and other tools can draw on them whenever they need to.

Get started in 15 minutes View on GitHub

How it works

1. Your notes in

Markdown, text, PDFs or GitHub repos. Munkymind reads them and builds a searchable library of who you are and what you're working on.

2. Ask from anywhere

Connect Claude Desktop, claude.ai or ChatGPT through MCP. They pull the right pages when a question needs your context.

3. Answers with sources

Every answer cites the notes it came from, and stale pages are flagged, so you can see why it said what it said.

Yours, and private

Runs on your machine

Self-host with Docker. Your notes and library stay on your computer.

Bring your own key

One OpenAI key is enough, or use Claude for answers. Want it fully local? Use Ollama and no key at all.

Open source

Apache 2.0 licensed. Read the code, change it, add your own connectors.

Get started

You need Docker, git and one OpenAI API key. Full checklist: Before you start.

  1. Download and add your key 
    git clone https://github.com/munkymind/munkymind.git
cd munkymind
cp .env.example .env      # then put your OPENAI_API_KEY in .env
  2. Add some notes and start it 
    mkdir -p notes && cp -r ~/path/to/your/notes/* notes/
docker compose up -d
  3. Run the setup wizard (creates your user, ingests your notes, test-queries) 
    docker compose exec api munkymind setup

    Save the mm_sk_… key it prints. Then ask: docker compose exec api munkymind query --user yourname "What am I working on?"

  4. Connect your AI tools. Claude Desktop works locally. For claude.ai or ChatGPT, give the MCP server a public HTTPS address (a free Cloudflare tunnel works) and add it as a custom connector. Step-by-step guide.
