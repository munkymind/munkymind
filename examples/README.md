# Examples

## sample-notes/

`sample-notes/` is a small, made-up library for trying Munkymind without using your own notes. "Sam" is fictional.

Use it by setting `MM_NOTES_DIR=./examples/sample-notes` in `.env` before `docker compose up -d`, or by copying the folders into `./notes`. Then follow [What can I do with it?](../docs/using-munkymind.md).
